Public · CORS open · no key

Partner API

Real EXP/hr and mesos/hr from players who share 15‑minute runs with the Maple Classic Exp Overlay best‑maps site. Use it from MapleBuddy, a wiki, a Discord bot, or your own tool.

Base

https://mcwo.app/api/v1

All GET responses are JSON with Access-Control-Allow-Origin: *. No API key. Please credit mcwo.app (every payload includes an attribution field).

Endpoints

  • GET /api/v1/maps?class=Thief&path=Night%20Lord&level=30&party=solo — ranked maps (slim)
  • GET /api/v1/ladder?class=Thief&path=Night%20Lord&party=solo — best map per 5‑level band
  • GET /api/v1/options — classes, paths, totals
  • GET /api/v1/recent — latest shared runs (public bar)
  • GET /api/v1 — this catalog as JSON

party is solo or party. Path names match the site (4th‑job names). The same data also lives under /api/stats, /api/ladder, etc. (full chart payloads).

Example

curl "https://mcwo.app/api/v1/maps?class=Thief&path=Night%20Lord&level=30&party=solo"
{

    { "map": "Dangerous Steam", "exp_hr": 67072, "mesos_hr": 52056, "players": 3, … }
  ]
}

Rules of the numbers

  • Only clean 15‑minute runs (opt‑in). Shop/storage/trade runs are never shared.
  • One player, one vote (median). Outliers dropped. A map ranks at 3+ players.
  • No character names, chat, screenshots, or install IDs in these answers.
